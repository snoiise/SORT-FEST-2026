# Sort Fest 2026

**A sorting algorithm competition**

Write a sorting algorithm in **Nim**, submit it, and see how it performs against the competition.

## Competition

Every submission is compiled using the same toolchain and tested using the same benchmark program and hardware.

The benchmark measures performance across different datasets, input sizes, and execution conditions.

Submissions are ranked using their benchmark results, with faster performance ranking higher.

## Categories

| Category               | Description                                                             |
| ---------------------- | ----------------------------------------------------------------------- |
| **Overall**            | Ranked using performance across the full benchmark.                     |
| **Random**             | Ranked using performance on randomly generated data.                    |
| **Adversarial**        | Ranked using performance against difficult inputs.                      |
| **Adaptive**           | Ranked using how well the algorithm adapts to different input patterns. |
| **Lowest Memory**      | Ranked using the amount of memory used while sorting.                   |
| **Single-threaded**    | Ranked using performance with a single CPU thread.                      |
| **Multithreaded**      | Ranked using performance with multiple CPU threads.                     |
